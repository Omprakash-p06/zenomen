# Plan 04-01: Tray, Autostart, Close-to-Tray & Single-Instance D-Bus Service

## Context

Phase 4 integrates ZenOmen naturally into Linux desktop environments (GNOME, KDE, Cinnamon, XFCE). Modern Linux desktops require single-instance enforcement, system tray access, close-to-tray lifecycle management, and login autostart. Critically, to preserve ZenOmen's strict resource budget (PERF-01: $\le 40$ MB peak RSS, $\le 25$ MB minimized in tray), tray integration must be implemented natively over `zbus` using the freedesktop StatusNotifierItem (SNI) protocol, without pulling in heavy C dependencies like GTK4 or Tao. On desktop environments where tray icons are not available (such as stock GNOME without extensions), single-instance D-Bus activation (`com.zenomen.App` `PresentWindow`) provides a reliable 100% fallback (SYS-05, SYS-10).

## Objectives

1. Implement single-instance session D-Bus service (`com.zenomen.App`) with `PresentWindow` and `Quit` methods.
2. Implement native `zbus` StatusNotifierItem (`org.kde.StatusNotifierItem`) and DBusMenu (`com.canonical.dbusmenu`) for the system tray without linking GTK/Qt.
3. Manage window visibility for `--minimized` startup and close-to-tray lifecycle.
4. Manage XDG autostart at login (`~/.config/autostart/zenomen.desktop`).
5. Ensure graceful degradation when `StatusNotifierWatcher` is absent (SYS-10).

## Tasks

### Task 1: Single-Instance Session D-Bus Service (`src/desktop/single_instance.rs`)
- Register `com.zenomen.App` on the user session bus.
- If name is already owned:
  - Invoke `PresentWindow()` on `com.zenomen.App` (`/com/zenomen/App`).
  - Exit current process with code 0.
- If name is acquired:
  - Expose D-Bus interface `com.zenomen.App` with:
    - `PresentWindow()`: sends an internal command to restore/show and focus the Slint window.
    - `Quit()`: cleanly exits the application event loop.

### Task 2: Pure `zbus` StatusNotifierItem System Tray (`src/desktop/tray.rs`)
- Implement `org.kde.StatusNotifierItem` interface:
  - Properties: `Category = "ApplicationStatus"`, `Id = "zenomen"`, `Title = "ZenOmen"`, `Status = "Active"`, `IconName = "zenomen"`.
  - Methods:
    - `Activate(x: i32, y: i32)`: triggers `PresentWindow` / toggles window visibility.
    - `ContextMenu(x: i32, y: i32)`: triggers context menu display.
- Implement `com.canonical.dbusmenu` at `/MenuBar`:
  - Items:
    - Open ZenOmen
    - Current Profile readout (e.g. "Profile: Balanced")
    - Diagnostics Screen
    - Launch at Login (toggle)
    - Quit ZenOmen
- Register with `org.kde.StatusNotifierWatcher`. If watcher is absent, log informational trace and continue without error.

### Task 3: Close-to-Tray & Lifecycle Coordination (`src/main.rs`, `src/app.rs`)
- Add command-line argument parsing for `--minimized` / `-m`.
- When starting minimized, do not call `window.show()` immediately.
- Intercept window close request:
  - If `close_to_tray` is enabled, invoke `window.hide()`.
  - If `close_to_tray` is disabled or Quit is explicitly triggered, terminate event loop and exit.

### Task 4: XDG Autostart Manager (`src/desktop/autostart.rs`)
- Resolve `~/.config/autostart/zenomen.desktop` using `directories::BaseDirs`.
- Implement `is_autostart_enabled() -> bool`:
  - Returns true if desktop entry exists and does not specify `Hidden=true`.
- Implement `set_autostart_enabled(enabled: bool) -> Result<(), std::io::Error>`:
  - When true: writes `.desktop` file containing `Name=ZenOmen`, `Exec=zenomen --minimized`, `Icon=zenomen`, `Terminal=false`.
  - When false: removes file or writes `Hidden=true`.

### Task 5: Integration Tests (`tests/desktop_integration_tests.rs`)
- Test XDG autostart file generation, parsing, and deletion.
- Test `com.zenomen.App` interface serialization and method dispatch.
- Test StatusNotifierItem properties and menu generation.

## Verification Criteria

- `cargo clippy --all-targets -- -D warnings` passes with 0 warnings.
- `cargo test --test desktop_integration_tests` passes cleanly.
- Running `zenomen` while an existing instance runs focuses the existing window and exits 0.
