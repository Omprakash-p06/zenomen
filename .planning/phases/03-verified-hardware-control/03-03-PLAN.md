# Plan 03-03: ACPI Power Profiles, Combined Presets & Hardware Service Diagnostics

## Objective
Implement interactive ACPI power profile switching and combined presets (Quiet, Balanced, Gaming) in the GUI, reporting granular results honestly through `PresetResult`. Add hardware service connection and polkit permission diagnostics to the Diagnostics screen and export report (**PWR-01**, **PWR-02**, **PWR-03**, **PWR-04**, **PWR-05**, **PWR-06**, **DIAG-04**).

## Context & Design Rules
- Follow [`03-RESEARCH.md`](file:///home/omprakash/Documents/zenomen/.planning/phases/03-verified-hardware-control/03-RESEARCH.md) specifications for power profiles and presets:
  - **Dynamic Choices & Active Profile (PWR-01, PWR-02):**
    - Populate choices strictly from `/sys/firmware/acpi/platform_profile_choices` (e.g. `quiet`, `balanced`, `performance`, `cool`, etc.).
    - Display currently active profile read from `/sys/firmware/acpi/platform_profile`.
  - **Applying Power Profiles & Verification (PWR-03, PWR-04):**
    - Allow user to select any advertised profile.
    - Write to sysfs via `HardwareServiceClient::set_power_profile`.
    - Every write is verified with retry/backoff in `zenomen-hw`; failure reports `VerificationFailed`.
  - **Combined Presets & Granular Result (PWR-05, PWR-06):**
    - Expose 3 combined presets:
      - **Gaming**: Performance power profile + Max fan mode.
      - **Balanced**: Balanced power profile + Auto fan mode.
      - **Quiet**: Cool/Quiet power profile + Auto fan mode.
    - When user applies a preset, daemon applies power profile and fan mode in sequence.
    - Result is returned as `PresetResult`:
      ```rust
      pub struct PresetResult {
          pub preset_name: String,
          pub power_applied: bool,
          pub fan_applied: bool,
          pub partial_success: bool,
          pub message: String,
      }
      ```
    - If power profile succeeds but fan mode fails (or vice versa), UI displays a warning banner highlighting partial success honestly: e.g. `"Preset 'Gaming' partially applied: power profile set to performance, but fan mode write failed"`.
  - **Hardware Service & Polkit Diagnostics (DIAG-04):**
    - Probe `zenomen-hw` via D-Bus ping/capabilities check.
    - Report connection status: `Connected`, `Disconnected`, or `Unavailable`.
    - Report polkit permission check status: `Authorized` or `Requires Authentication / Challenged`.
    - Include in both UI Diagnostics screen and the JSON/text diagnostics export file.
