# Plan 06-05: Windows Desktop Integration, Packaging & Dual-OS CI

## Objective
Implement native Windows desktop integration (system tray, single-instance mutex, user-level autostart) and author the dual-platform CI/CD and release packaging pipelines for Linux and Windows 10/11.

## Tasks

### Task 1: Windows Desktop Integration
- In `src/desktop/windows/`:
  - `tray.rs`: Implement system tray icon using `Shell_NotifyIconW` (`NOTIFYICONDATAW`), supporting icon display, tooltips, and `TrackPopupMenu` context menu (Show, Fan Mode, Quit).
  - `single_instance.rs`: Implement session mutex (`CreateMutexW`) preventing duplicate processes, with secondary instance window presentation trigger.
  - `autostart.rs`: Implement non-destructive user autostart using `RegSetValueExW` / `RegDeleteValueW` under `Software\Microsoft\Windows\CurrentVersion\Run`.
  - Wire platform desktop modules into `src/desktop/mod.rs` and `src/main.rs`.

### Task 2: Dual-Platform CI Matrix
- In `.github/workflows/ci.yml`:
  - Configure matrix build:
    - `linux`: `ubuntu-latest` running fmt, clippy, `xvfb-run -a cargo test --all`, cargo audit.
    - `windows`: `windows-latest` running `cargo check`, clippy, and unit tests with `x86_64-pc-windows-msvc`.

### Task 3: Dual-Platform Release Pipeline
- In `.github/workflows/release.yml`:
  - Build Linux `.deb` and `.AppImage` packages.
  - Build Windows signed/executable package (`zenomen.exe`, `zenomen-hw.exe`, embedded icon and manifest).
  - Generate consolidated `SHA256SUMS` file and attach all release assets to the GitHub Release.
- Update `docs/PACKAGING.md` with Windows installation, service registration, and verification instructions.
