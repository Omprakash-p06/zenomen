# Plan 06-02: Cross-Platform Domain Contracts & Provider Seams

## Objective
Refactor and formalize the core domain types and telemetry contracts so that Linux and Windows providers fulfill the identical interface with complete test isolation and zero host-system leakage.

## Tasks

### Task 1: Expand Cross-Platform Telemetry Model
- In `src/hardware/provider.rs`:
  - Add explicit battery fields to `TelemetrySnapshot`:
    ```rust
    pub battery_percent: Option<u8>,
    pub battery_charging: Option<bool>,
    pub battery_remaining_seconds: Option<u32>,
    ```
  - Update `has_battery_metrics` predicate.
  - Implement conversion helpers and update mock provider in `src/hardware/mock.rs`.

### Task 2: Root Isolation for Capability Detection
- In `src/hardware/registry.rs` and `src/hardware/rgb.rs`:
  - Modify `detect_capabilities` to pass the registry's configured root into `detect_rgb_interface` instead of hardcoding `Path::new("/")`.
  - Align fan control predicate: ensure `SensorRegistry` only reports `has_fan_control = true` for devices matching the HP driver name (`hp-wmi` / `hp`), preventing divergence with `src/service/backend.rs`.

### Task 3: History Window Unit & Conversion Alignment
- In `src/core/telemetry.rs` and `src/core/worker.rs`:
  - Convert configured history window seconds into sample capacity:
    `capacity = max(10, seconds * 1000 / polling_interval_ms)`.
  - Recompute buffer bounds dynamically when polling interval changes.
  - Cache SVG chart paths to avoid redundant string allocations when telemetry data has not changed.
