### Task 2: Linux Battery Telemetry Sampling
1. **Sysfs Reader in `src/hardware/linux/provider.rs`**:
   Implement `sample_battery(root: &Path) -> Option<BatteryTelemetry>`:
   - Enumerate `/sys/class/power_supply/BAT*`.
   - Read `capacity` → parse `u8` (clamped 0..=100).
   - Read `status` → `"Charging"` = `Some(true)`, other states = `Some(false)`.
   - Read `time_to_empty_now` / `time_to_full_now` if present → convert $\mu s$ to seconds.
   - If no battery exists, return `None`.
2. **Populate in `LinuxHardwareProvider::sample()`**.

### Task 4: Fix History Window Duration Calculation
1. **Duration vs Samples Math in `src/core/telemetry.rs:25-65`**:
   ```rust
   impl TelemetryHistory {
       pub fn new_with_duration(duration_seconds: u32, interval_ms: u64) -> Self {
           let capacity = (duration_seconds as u64 * 1000 / interval_ms.max(100)).max(10) as usize;
           Self {
               capacity,
               duration_seconds,
               samples: VecDeque::with_capacity(capacity),
               cached_svg_paths: None,
           }
       }

       pub fn update_interval(&mut self, interval_ms: u64) {
           let new_capacity = (self.duration_seconds as u64 * 1000 / interval_ms.max(100)).max(10) as usize;
           self.capacity = new_capacity;
           while self.samples.len() > self.capacity {
               self.samples.pop_front();
           }
           self.cached_svg_paths = None;
       }
   }
   ```
2. **Dynamic Resizing in `src/core/worker.rs:156-205`**:
   When receiving `AppCommand::SetHistoryWindow(seconds)`:
   - Call `history.set_duration(seconds, current_interval_ms)`.
   When receiving `AppCommand::SetPollingInterval(ms)`:
   - Call `history.update_interval(ms)`.
3. **SVG Path Caching**:
   Cache generated SVG paths in `cached_svg_paths: Option<(String, String, String)>` (CPU, GPU, RAM) and only regenerate when new samples are appended or window capacity changes.
