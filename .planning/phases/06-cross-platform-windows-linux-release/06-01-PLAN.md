# Plan 06-01: Linux Hardening & Concerns Remediation

## Objective
Resolve all open technical debt, security issues, and fragile areas in the Linux codebase as documented in `.planning/codebase/CONCERNS.md`, establishing an unassailable Linux baseline before expanding cross-platform functionality.

## Tasks

### Task 1: D-Bus & Systemd Service Hardening
- Update `data/dbus/com.zenomen.Hardware1.service` to add `SystemdService=zenomen-hw.service` so D-Bus activation delegates to systemd rather than spawning unconfined daemon instances.
- Update `data/systemd/zenomen-hw.service` to add explicit sandbox paths:
  ```ini
  ReadWritePaths=-/sys/devices/platform/hp-wmi -/sys/class/hwmon
  ```
- Update `src/desktop/system_integration.rs` to ensure system integration installation and uninstallation synchronize both updated service files.

### Task 2: RGB State Preservation on Toggle
- Modify `src/service/contract.rs` and `src/core/state.rs`:
  - Cache the last applied `RgbProfile` before disabling RGB.
  - On `SetRgbEnabled(true)`, restore the cached profile rather than applying hardcoded white (`#FFFFFF`).
  - Route RGB client calls in `src/service/client.rs` through `connect_service()` so offline daemon errors provide actionable systemd guidance.

### Task 3: Desktop Lifecycle & Shutdown Fixes
- Fix session D-Bus absence shutdown hang in `src/main.rs`:
  - Call `drop(action_sender)` explicitly after single-instance setup so `action_receiver` cleanly disconnects when the window closes, avoiding thread join hangs in standalone mode.
- Update `src/desktop/autostart.rs`:
  - Implement non-destructive autostart toggle by updating `Hidden=true` or `X-GNOME-Autostart-enabled=false` rather than deleting the desktop entry.
  - Reconcile config autostart flag with actual desktop entry state on startup.

### Task 4: Telemetry & Benchmark Accuracy
- Update `src/core/benchmark.rs`:
  - Dynamically read `CLK_TCK` via `getconf CLK_TCK` or `sysconf(_SC_CLK_TCK)` with fallback to 100, eliminating CPU percentage distortion on non-100Hz kernels.
- Update `src/service/client.rs`:
  - Replace developer build path references (`sudo target/debug/...`) in offline error messages with standard package instructions (`sudo systemctl start zenomen-hw`).
