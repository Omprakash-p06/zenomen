# Plan 06-03: Windows Native Telemetry Engine

## Objective
Implement a production-grade, native Windows telemetry engine under `src/hardware/windows/`. It directly queries Windows C/COM APIs (Win32, DXGI, PDH, Power) to provide accurate CPU, RAM, GPU, and battery telemetry matching the `HardwareProvider` trait, with zero Linux dependencies and zero fabricated zeros.

## User-Facing Impact
- **Real Windows Dashboard**: Users running ZenOmen on Windows 10/11 see live, accurate graphs of CPU load, clock speed, physical RAM usage, GPU VRAM and utilization, and battery charge status.
- **Zero Runtime Bloat**: Telemetry uses direct Win32 OS calls taking <1ms per tick, easily satisfying the ≤0.1% idle CPU requirement.

### Step 2: Native CPU Telemetry (`src/hardware/windows/cpu.rs`)
1. **Delta Utilization via `GetSystemTimes`**:
   ```rust
   pub struct WindowsCpuSampler {
       last_idle: u64,
       last_kernel: u64,
       last_user: u64,
       model_name: Option<String>,
   }

   impl WindowsCpuSampler {
       pub fn new() -> Self {
           let mut sampler = Self {
               last_idle: 0,
               last_kernel: 0,
               last_user: 0,
               model_name: query_processor_name(),
           };
           let _ = sampler.sample_utilization(); // Initialize baseline tick
           sampler
       }

       pub fn sample_utilization(&mut self) -> Option<f32> {
           let mut idle = FILETIME::default();
           let mut kernel = FILETIME::default();
           let mut user = FILETIME::default();
           // SAFETY: GetSystemTimes writes three valid FILETIME structs
           if unsafe { GetSystemTimes(&mut idle, &mut kernel, &mut user) } == 0 {
               return None;
           }
           let idle_u64 = filetime_to_u64(&idle);
           let kernel_u64 = filetime_to_u64(&kernel);
           let user_u64 = filetime_to_u64(&user);

           let delta_idle = idle_u64.saturating_sub(self.last_idle);
           let delta_kernel = kernel_u64.saturating_sub(self.last_kernel);
           let delta_user = user_u64.saturating_sub(self.last_user);
           let delta_total = delta_kernel + delta_user;

           self.last_idle = idle_u64;
           self.last_kernel = kernel_u64;
           self.last_user = user_u64;

           if delta_total == 0 {
               return None;
           }
           let util = 100.0 * (1.0 - (delta_idle as f32 / delta_total as f32));
           Some(util.clamp(0.0, 100.0))
       }
   }
   ```
2. **Frequency via `CallNtPowerInformation`**:
   Query `ProcessorInformation` to obtain `PROCESSOR_POWER_INFORMATION` and extract `CurrentMhz` as `cpu_frequency`.

### Step 3: Native Memory Telemetry (`src/hardware/windows/memory.rs`)
1. **`GlobalMemoryStatusEx` Sampling**:
   ```rust
   pub fn sample_memory() -> (Option<u32>, Option<u32>) {
       let mut status = MEMORYSTATUSEX {
           dwLength: std::mem::size_of::<MEMORYSTATUSEX>() as u32,
           ..Default::default()
       };
       // SAFETY: dwLength is set, Windows writes valid memory info
       if unsafe { GlobalMemoryStatusEx(&mut status) } == 0 {
           return (None, None);
       }
       let total_mb = (status.ullTotalPhys / (1024 * 1024)) as u32;
       let avail_mb = (status.ullAvailPhys / (1024 * 1024)) as u32;
       let used_mb = total_mb.saturating_sub(avail_mb);
       (Some(used_mb), Some(total_mb))
   }
   ```

### Step 4: Native GPU Telemetry (`src/hardware/windows/gpu.rs`)
1. **DXGI Adapter Enumeration**:
   - Query DXGI 1.3 `CreateDXGIFactory1`.
   - Iterate adapters via `EnumAdapters1`.
   - Skip software renderers (`DXGI_ADAPTER_FLAG_SOFTWARE`).
   - Extract adapter description from `DXGI_ADAPTER_DESC1` (converting UTF-16 slice to Rust `String`).
   - Dedicated VRAM: `DedicatedVideoMemory / (1024 * 1024)` MB.
2. **Engine Sampling via PDH**:
   Initialize PDH query for `\GPU Engine(*)\Utilization Percentage`. Sample delta without blocking the thread. If PDH counter is uninitialized, return `None` gracefully.

### Step 5: Native Battery Telemetry (`src/hardware/windows/battery.rs`)
1. **`GetSystemPowerStatus` Sampling**:
   ```rust
   pub fn sample_battery() -> (bool, Option<u8>, Option<bool>, Option<u32>) {
       let mut status = SYSTEM_POWER_STATUS::default();
       if unsafe { GetSystemPowerStatus(&mut status) } == 0 {
           return (false, None, None, None);
       }
       let present = status.BatteryFlag != 128; // 128 = No system battery
       let percent = if status.BatteryLifePercent <= 100 {
           Some(status.BatteryLifePercent)
       } else {
           None
       };
       let charging = Some((status.BatteryFlag & 8) != 0);
       let remaining_sec = if status.BatteryLifeTime != 0xFFFFFFFF {
           Some(status.BatteryLifeTime)
       } else {
           None
       };
       (present, percent, charging, remaining_sec)
   }
   ```
