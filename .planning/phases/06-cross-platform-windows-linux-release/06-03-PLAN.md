# Plan 06-03: Windows Native Telemetry Engine

## Objective
Implement a production-grade, native Windows hardware provider under `src/hardware/windows/` that reads telemetry directly via Windows C/COM APIs (Win32, DXGI, PDH, Power) without any external shell commands or fake zero fallbacks.

## Tasks

### Task 1: Windows Target Dependencies & Module Tree
- In `Cargo.toml`:
  - Add target-specific dependencies under `[target.'cfg(windows)'.dependencies]`:
    ```toml
    [target.'cfg(windows)'.dependencies]
    windows-sys = { version = "0.59", features = [
        "Win32_Foundation",
        "Win32_System_SystemInformation",
        "Win32_System_Power",
        "Win32_System_Performance",
        "Win32_Graphics_Dxgi",
    ] }
    ```
- Create module tree `src/hardware/windows/`:
  - `mod.rs`, `provider.rs`, `cpu.rs`, `memory.rs`, `gpu.rs`, `battery.rs`.
- In `src/hardware/mod.rs`, export `WindowsHardwareProvider` when `target_os = "windows"`.

### Task 2: CPU & Memory Telemetry
- `src/hardware/windows/cpu.rs`:
  - Calculate aggregate CPU utilization using `GetSystemTimes` (idle vs total kernel+user time deltas).
  - Query processor frequency and friendly model name via `CallNtPowerInformation` (`ProcessorInformation`).
- `src/hardware/windows/memory.rs`:
  - Query total and available physical RAM via `GlobalMemoryStatusEx` (`MEMORYSTATUSEX`).
  - Calculate `ram_used_mb = (ullTotalPhys - ullAvailPhys) / (1024 * 1024)`.

### Task 3: GPU & Battery Telemetry
- `src/hardware/windows/gpu.rs`:
  - Enumerate display adapters via DXGI `CreateDXGIFactory1` and `EnumAdapters1`.
  - Extract dedicated video memory, vendor ID, and description via `GetDesc1`.
  - Query engine utilization through PDH counters (`\GPU Engine(*)\Utilization Percentage`).
- `src/hardware/windows/battery.rs`:
  - Query battery presence, percentage, and AC charging status via `GetSystemPowerStatus`.

### Task 4: Integration with Main GUI
- Wire `WindowsHardwareProvider` into `src/main.rs` when `cfg(target_os = "windows")`, replacing the unavailable provider stub.

## Verification
- `cargo check --target x86_64-pc-windows-msvc`
- Cross-platform unit tests in `tests/windows_telemetry_tests.rs` (exercising parsers and mock Windows structs)
