# Plan 06-03: Windows Native Telemetry Engine

## Objective
Implement a production-grade, native Windows telemetry engine under `src/hardware/windows/` fulfilling the exact file layout, function signatures, and API contracts defined in Sections 3 and 5.1 of the cross-platform specification. Telemetry is sourced directly from Win32, DXGI, PDH, and Power APIs without calling shell utilities or fabricating zero values.

## Codebase Map References
- `STACK.md`: Windows compilation target (`--target x86_64-pc-windows-msvc`), dependencies, and build profiles.
- `ARCHITECTURE.md`: `HardwareProvider` trait and platform isolation.
- `CONVENTIONS.md`: Error handling (absence is not zero, unreadable metrics return `None`).

---

## Detailed Implementation Tasks

### Task 1: Windows Dependencies & Module Structure
1. **Configure `Cargo.toml`**:
   Add target-specific dependencies under `[target.'cfg(windows)'.dependencies]`:
   ```toml
   [target.'cfg(windows)'.dependencies]
   windows-sys = { version = "0.59", features = [
       "Win32_Foundation",
       "Win32_System_SystemInformation",
       "Win32_System_Power",
       "Win32_System_Performance",
       "Win32_System_Threading",
       "Win32_Graphics_Dxgi",
       "Win32_Security",
   ] }
   ```
2. **Directory Layout**:
   Create `src/hardware/windows/`:
   - `mod.rs`: Re-exports `WindowsHardwareProvider`.
   - `provider.rs`: Implements `HardwareProvider`.
   - `cpu.rs`: CPU sampling functions.
   - `memory.rs`: RAM sampling functions.
   - `gpu.rs`: GPU enumeration and metrics.
   - `battery.rs`: Battery status.
   - `sensors.rs`: Thermal and fan readings.
   - `device.rs`: Board and device identity.
3. **Wire in `src/hardware/mod.rs`**:
   ```rust
   #[cfg(target_os = "linux")]
   pub use linux::LinuxHardwareProvider;

   #[cfg(target_os = "windows")]
   pub use windows::WindowsHardwareProvider;

   #[cfg(not(any(target_os = "linux", target_os = "windows")))]
   pub use unavailable::UnavailableHardwareProvider;
   ```

### Task 2: CPU Telemetry (`src/hardware/windows/cpu.rs`)
Implement the functions specified in Section 5.1:
1. `pub fn read_cpu_utilization(sampler: &mut WindowsCpuSampler) -> Option<f32>`:
   Calls `GetSystemTimes(&idle, &kernel, &user)`. Calculates:
   $$\Delta \text{Kernel} = \text{kernel}_t - \text{kernel}_{t-1}, \quad \Delta \text{User} = \text{user}_t - \text{user}_{t-1}, \quad \Delta \text{Idle} = \text{idle}_t - \text{idle}_{t-1}$$
   $$\text{Util} = 100.0 \times \left(1.0 - \frac{\Delta \text{Idle}}{\Delta \text{Kernel} + \Delta \text{User}}\right)$$
   Clamps result to `0.0..=100.0`. Returns `None` if delta total is zero.
2. `pub fn read_cpu_frequency() -> Option<f32>`:
   Calls `CallNtPowerInformation(ProcessorInformation, ...)` to extract `CurrentMhz` from `PROCESSOR_POWER_INFORMATION`.
3. `pub fn read_cpu_model() -> Option<String>`:
   Queries registry key `HARDWARE\DESCRIPTION\System\CentralProcessor\0\ProcessorNameString` or WMI `Win32_Processor.Name`.

### Task 3: Memory Telemetry (`src/hardware/windows/memory.rs`)
Implement:
1. `pub fn read_ram_usage() -> (Option<u32>, Option<u32>)`:
   Calls `GlobalMemoryStatusEx(&mut status)` with `dwLength` initialized.
   - `total_mb = (status.ullTotalPhys / (1024 * 1024)) as u32`
   - `avail_mb = (status.ullAvailPhys / (1024 * 1024)) as u32`
   - `used_mb = total_mb.saturating_sub(avail_mb)`
   - Returns `(Some(used_mb), Some(total_mb))`.

### Task 4: GPU Telemetry (`src/hardware/windows/gpu.rs`)
Implement:
1. `pub fn enumerate_gpu_adapters() -> Vec<GpuAdapterInfo>`:
   Calls DXGI 1.3 `CreateDXGIFactory1` and iterates `IDXGIFactory1::EnumAdapters1`. Filters out software emulators (`DXGI_ADAPTER_FLAG_SOFTWARE`).
2. `pub fn read_gpu_identity(adapter: &IDXGIAdapter1) -> (String, u32, u32)`:
   Extracts `Description` (converted from UTF-16), `VendorId`, and `DeviceId` from `DXGI_ADAPTER_DESC1`. Recognizes NVIDIA (`0x10DE`), AMD (`0x1002`), Intel (`0x8086`).
3. `pub fn sample_gpu_memory(adapter: &IDXGIAdapter1) -> (Option<u32>, Option<u32>)`:
   - Dedicated VRAM: `DedicatedVideoMemory / (1024 * 1024)` MB.
   - Queries `IDXGIAdapter3::QueryVideoMemoryInfo` for application budget and current reservation.
4. `pub fn sample_gpu_utilization(pdh_query: &mut WindowsPdhQuery) -> Option<f32>`:
   Queries PDH counter `\GPU Engine(*)\Utilization Percentage` via `PdhCollectQueryData` and `PdhGetFormattedCounterValue`, aggregating across graphics/3D engines.
5. `pub fn read_gpu_temperature(vendor_id: u32) -> Option<f32>`:
   Queries vendor-specific interface or WMI thermal zone; returns `None` if unsupported rather than fabricating zero.

### Task 5: Battery Telemetry (`src/hardware/windows/battery.rs`)
Implement:
1. `pub fn read_battery_presence() -> bool`:
   Calls `GetSystemPowerStatus(&status)`; returns `status.BatteryFlag != 128`.
2. `pub fn sample_battery_telemetry() -> Option<BatteryTelemetry>`:
   Calls `GetSystemPowerStatus(&status)`.
   If `status.BatteryFlag == 128`, returns `None`.
   Otherwise returns:
   ```rust
   Some(BatteryTelemetry {
       present: true,
       charge_percent: if status.BatteryLifePercent <= 100 { Some(status.BatteryLifePercent) } else { None },
       charging: Some((status.BatteryFlag & 8) != 0),
       remaining_seconds: if status.BatteryLifeTime != 0xFFFFFFFF { Some(status.BatteryLifeTime) } else { None },
   })
   ```

### Task 6: Temperature, Fans & Device Identity (`sensors.rs`, `device.rs`)
1. **Sensors in `src/hardware/windows/sensors.rs`**:
   - `enumerate_sensor_sources()`: Resolves available WMI and hardware monitoring sources.
   - `read_temperature_sensors()`: Returns CPU/GPU temperatures or `None`.
   - `read_fan_rpms()`: Queries HP WMI command `0x11` when verified; returns empty `Vec` when unavailable.
2. **Device Identity in `src/hardware/windows/device.rs`**:
   - `read_system_identity() -> (String, String)`: Queries `Win32_ComputerSystem.Manufacturer` and `Model`.
   - `read_board_id() -> Option<String>`: Queries `Win32_BaseBoard.Product`.
   - `enumerate_pnp_devices()`: Enumerates PnP display and battery devices.

### Task 7: `WindowsHardwareProvider` Integration
In `src/hardware/windows/provider.rs`:
- Implements `HardwareProvider`:
  - `capabilities()`: Dynamic capabilities derived from device and battery presence.
  - `sample()`: Queries CPU, RAM, GPU, and battery; returns clean `TelemetrySnapshot`.
- Wire into `src/main.rs:190-230` under `#[cfg(target_os = "windows")]`.
