# Plan 01-01: Rust + Slint Scaffold, Build Pipeline, Theme Tokens & CI Gates

## Objective
Establish the compiled Rust (edition 2024) + Slint 1.17 project structure with theme tokens matching `01-UI-SPEC.md` verbatim, vendored font assets, minimal application entry point, `.gitignore`, and GitHub Actions CI quality gates (`cargo fmt`, `cargo clippy -D warnings`, `cargo test` under `xvfb`, `cargo audit`).

## Context & Design Rules
- Follow [`01-UI-SPEC.md`](file:///home/omprakash/Documents/zenomen/.planning/phases/01-foundation-gui-shell-on-mock-hardware/01-UI-SPEC.md) for exact theme hex values, font families (Inter, JetBrains Mono), spacing scale (multiples of 4), and structural dimensions.
- Use release profile optimizations in `Cargo.toml` (`opt-level = "s"`, `lto = true`, `strip = true`, `panic = "abort"`, `codegen-units = 1`) to uphold the ≤40 MB RSS budget.
- Pin Slint and `slint-build` to `1.17` with `default-features = false`, `backend-winit`, and `renderer-femtovg`.
- Commit `Cargo.lock` to ensure deterministic builds and supply the dependency graph for `cargo audit`.
