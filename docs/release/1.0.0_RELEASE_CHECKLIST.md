## 4. Hardware Safety & Telemetry Integrity

- [ ] **8A3D / F.22 Auto Fan Safety:**
  - [ ] Zero-RPM at cold idle recognized as normal passive cooling policy.
  - [ ] Max Fan command spools fans up to ~5400 RPM (CPU) and ~5200 RPM (GPU).
  - [ ] Auto mode restoration executes safe sequence: disable Max Fan `0x27=0`, arm window `0x10`, reapply profile `0x1A`.
  - [ ] Forbidden opcode `0x2E {0,0}` strictly avoided on 8A3D.
  - [ ] Thermal load ramp confirmed: fans resume spinning under load before CPU reaches 70°C.
- [ ] **Hardware Registry Honesty:**
  - [ ] Manual PWM and RGB remain marked `Unsupported` on 8A3D.
  - [ ] Thermal profile status labeled unverified where EC readback is absent.
  - [ ] Unrecognized motherboards fail closed.
- [ ] **Process Memory Telemetry:**
  - [ ] GUI Working Set, GUI Private, Service Working Set, Service Private reported cleanly.
  - [ ] When service is disconnected, service metrics report "Unavailable" (no fabricated 0 MB).
  - [ ] Combined memory requires fresh measurements (≤10s difference).
